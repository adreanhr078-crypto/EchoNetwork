# Sector 11 Cryo Docking Dais v1

## Files

- `build_cryo_dais.py` is the editable Blender build recipe.
- `sector11-cryo-dais-v1.blend` is the editable Blender source.
- `sector11_cryo_dais_v1.glb` is the Godot export; its project copy is in `godot/assets/environment/`.
- `sector11-cryo-dais-v1.png` is the Blender material/render review.
- `godot-sector11-cryo-dais-review-v1.png` is the 1280×720 Godot runtime frame; the 6-second movie is alongside it.

The open-frame rails, isolation pads, synchronization rings, bolts, hazard bars, and bay label sit around the cryopod without lifting or replacing its imported model. It adds visual scale and a readable focal area to the otherwise flat floor. It has no separate collision; the existing corridor floor remains the walkable surface.

This is a local Blender asset; it used no Tripo or Google Flow credits. It is an intermediate art pass and still needs a detailed lighting, surface, and character review.
