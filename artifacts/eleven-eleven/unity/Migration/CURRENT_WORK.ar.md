## نقل المتابعة إلى حساب آخر

استنسخ مستودع GitHub العام مرة واحدة أو أعد استعمال نسخته الموجودة. استعمل Git LFS عند الحاجة إلى أصول Godot التاريخية.

```powershell
$env:GIT_LFS_SKIP_SMUDGE = '1'
git clone --filter=blob:none --sparse --branch unity/station-walls-2026-11-18 --single-branch --depth 1 https://github.com/adreanhr078-crypto/EchoNetwork.git
cd EchoNetwork
git sparse-checkout set artifacts/eleven-eleven/unity artifacts/eleven-eleven/docs .agents/skills .codex/skills
Remove-Item Env:GIT_LFS_SKIP_SMUDGE
```

افتح `artifacts/eleven-eleven/unity` في Unity Hub. أصول مشروع Unity تأتي مباشرة مع الفرع. عند الحاجة إلى شجرة Godot نفّذ `git sparse-checkout add artifacts/eleven-eleven/godot` مع `GIT_LFS_SKIP_SMUDGE=1` أولًا. أصول Godot التاريخية المخزنة في LFS تحتاج حصة متاحة على المستودع أو نسخة مؤهلة من الكاش الأصلي عند مراجعة الغرف. رفض خادم LFS الرفع أثناء التسليم بسبب نفاد الحصة، لذلك أُدرجت كل ملفات Unity في Git مباشرة. تأتي جلسة Unity والرصيد والصلاحيات من حسابك الحالي. تصدير Windows قابل للإعادة عبر [أداة البناء](Tools/BuildWindows.ps1) و[أداة الفحص](Tools/TestWindows.ps1). سجل البناء الأصلي يحمل بصمات المشاهد ومكوّنات الحزمة واللقطات الفعلية.

انقل اللعبة كاملة بنفس الكانون والتفاصيل والتتابع والتفاعلات من Godot. ارفع جودة الغرف التي تحتاج تدخّلًا بمقارنة متماثلة، مع إخراج Hyper Anime وطموح بصري وتجربة لعب تتجاوز مرجع Genshin Impact. الزجاج الملوّن الخفيف، الحركة الدقيقة، استجابة الضغط، المقروئية والمشهد الكامل هي معيار الواجهة. حافظ على الهوية الخاصة بـ11.11. قِس الجودة من اللعب الفعلي والمقارنة ومراجعة المالك.

الافتتاح المطلوب يتسلسل من حل قطع الغلاف وتكسّر الشاشة إلى مغادرة إيكو المدرسة مع أصدقائه، ثم دخوله المختبر وحده، وأسئلة الأب، والتجربة ومعاناتها وذكريات خاطفة أثناءها، ثم بوابة الانتقال ونجاح التجربة وواجهة النظام واستيقاظ School65. الفيديو الجديد والصورة يترقيان عند إثبات تحسن الإخراج واستمرارية الهوية. احتفظ بمصادر Godot وببدائل الافتتاح. استخدم Google Flow للأفلام الجديدة. الصوت بيئي ودرامي ووظيفي تحت سياسة `SFX_ONLY`، مع الكتم والحركة المخفّضة. ElevenLabs متاح عند احتياج محدد للصوت ومراجعة المصدر والتكلفة.

اعمل فرديًا كما طلب المالك. ابدأ من الكاش والبصمات والمقاطع المستوردة، واستعمل مخزن Unity الموجود بنفس الإصدار. أعد بناء الجزء المتأثر فقط. أعد استخدام مخرجات Flow ومعرّفاتها قبل أي توليد جديد. فحوص هذا الافتتاح معلّمة بنطاقها، والحكم البصري وفهم اللاعب يتطلبان اختبارًا مستقلًا.

## ما يعمل الآن

- زر عنوان واحد شفاف وملوّن. يعرض بدء اللعبة عند غياب الحفظ أو المتابعة عند وجود حفظ صالح. يظهر بعد تحضير الوجهة. تتركز شاشة التهيئة والصوت الاختياري في بداية الرحلة.
- الغلاف الأصلي القابل للحل، معاينة مرجعية، سحب وإلغاء وتعريب، ثم تكسّر عند الحل. أربع لقطات 3D من Google Flow بصوت مضمّن ومؤثرات مادية. راجع [بصمات المقاطع ومصادرها](OpeningFlow3D.json) و[مصادر إعادة المونتاج](SourceMedia/OpeningFlow3D/).
- تخطي سينمائي شفاف بعد عشر ثوانٍ مشاهدة فعلية على الأقل، مع ظهور وتلاشٍ ورد فعل عند الضغط. تبديل الكتم والحركة وإيقاف المشهد. في الحركة المخفّضة، الصور الثابتة والتقدم اليدوي. تُجهّز الغرفة أثناء الغلاف والفيلم ويصبح زر الاستيقاظ قابلًا للضغط بعد جاهزيتها.
- الغرفة المستقرة هي R10. School65 من دخول اللعب. الساعة ثم الأثر الشخصي يكشفان المحطة. الضبط المرجعي 111 MHz و45° والتوافق السابع. المحطة وموصل الطاقة يفتحان البوابة، وحفظ ما بعد العبور يستأنف خلفها. حالة الحفظ مرتبطة بسلطة النظام؛ أي مكافأة أو تقدم شبكي يبقى لدى الخادم.
- [أدلة بطاقات R00–R12](README.ar.md) و[سجل الأحداث](Card-R11.json) يحفظان الإنجاز حسب البطاقة. خط الأساس وإقلاع School65، الاستعادة، قياسات التحميل، التهيئة، قراءة الوجه، الضوء والعبور أُنجزت بنطاق فحوصها. R12 هو نموذج ضغط الممر مع 11 فحصًا وصمام مستورد. مشهد هندسة R01 المرشّح محفوظ تحت `Review/EntryFidelity` للمقارنة. سجل الواجهة الحالي في [Evidence/OpeningUI](Evidence/OpeningUI/).

**أحدث ملاحظة من المالك.** المقاطع الحالية مرجع للمستوى البصري. المطلوب تسلسل متصل يُظهر جلوس إيكو كاملًا ويُظهر كينجا إلى جواره أثناء المعاناة. تفاصيل التصوير والصوت والاستمرارية في [مراجعة سينمائية المختبر](OpeningContinuity.ar.md). هذه مهمة إخراج للافتتاح بالتوازي مع R12، وحالتها مفتوحة.

## أول خطوة للنموذج التالي

1. استأنف **R12**. اقرأ [عقد متعة المهمات](../../docs/internal/production/MISSION_FUN_CONTRACT_2026-11-04.json) و[نموذج ضغط Godot](../../godot/tests/room01_pressure_review.gd)، ثم [نموذج Unity](Review/R12/Room01PressureTrial.cs) و[بروتوكول الجلسات](Review/R12/PLAYTEST.ar.md). ادمج في معاينة R12 حدود الممر وصمام التنفيس ومكان العودة الآمن والإشارة المقروءة. حافظ على المسار المستقر R10 حتى اجتياز فحوص الحركة والتعافي والحفظ.
2. سجّل خمس جلسات مستقلة للاعبين الجدد، ثم انتقل إلى R13 للتحكم والإشارات وR14 للقفز وR15 للحافة وفق [خطة R00–R59 الكاملة](../../docs/internal/production/PRODUCTION_RESET_2026-11-06.ar.md). كل بطاقة لها تبعيات وأدلة قبول. يستند ترتيبها إلى 40 حزمة و128 متطلبًا و53 حدثًا. احتفظ بترتيب المانهوا كما يحدده [السجل العربي الحالي](../../docs/internal/narrative/current/ar/manifest.json).
3. تبقى المصادقة الحية وتكامل الحفظ الشبكي، المختبر والعقد الصريح والتحول المرئي إلى Pact72 في الرحلة الفعلية، الانتقال إلى الغرفة التالية، تجربة اللمس والجهاز المرجعي ومستوى الجودة مقارنة بمرجع المالك ضمن العمل المفتوح. يبدأ اللعب بـSchool65. القتال وتقدم Pact بعد القبول القصصي الصريح. راجع البطاقات المفتوحة قبل توسيع النطاق.
