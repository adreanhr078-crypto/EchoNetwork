## Intake boundaries

- Keep the qualified Canvas65 school target distinct from the Tripo Workspace66 combat source. Compare rest matrices, hierarchy, scale and axes before mapping. The downloaded boxing source has 96 samples at 24Hz; do not label it 30Hz or run it through the frozen 30Hz FBX contract. Use the existing native glTF inspector, preserve its original clock, and diagnose separately before a measured target transfer.
- Reuse Run/Idle/Jump evidence only after checking identities and hashes. Close Walk's source/Blender/Godot gates before default-avatar integration. Follow `echo-golden-animation` for source motion and guard Golden before/after each motion stage. AnimationPlayer alone during fidelity qualification; blends/IK are later runtime presentation work.
- Current school source has 65 body bones, no facial shapes and no hair/garment chains. Never claim a runtime spring creates missing bones or that an animation file supplies facial expression. Inspect actual eligible geometry and author explicit accessory chains only on a derivative.
- Facial work starts with a reviewed semantic eyelid/eye/mouth selection and one complete blink. No guessed raw indices, automatic bounding-box face editing, floating eyelid substitutes or fallback shader masquerading as real eyelid closure. A template needs compatible geometry, measured alignment and verified license; Surface Deform alone is not a facial rig.
- Keep body weights, UV/PBR maps, source keys, identity and EX-011 intact. Rejected face prototypes are research only. Add emotion and visemes only after neutral/blink deformation survives close-up and body motion in both tools.
- Use one secondary-motion solver per chain. Inspect installed ClassDB methods/properties before coding; API availability is not collision, stability or performance acceptance. Solve cloth on the actual short school uniform, not a hypothetical cape. Foot IK is a later measured correction; never double-correct authored contacts.
- Integrate through the existing EchoPlayer, rig adapter, DynamicActionCameraRig and Hyper Anime modules. Preserve save/contract authority, no powers before Zero, pause/mute/Reduced Motion and cinematic camera ownership. Keep prototype review projects separate from default runtime.
