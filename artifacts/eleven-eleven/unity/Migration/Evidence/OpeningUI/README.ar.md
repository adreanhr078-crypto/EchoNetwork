# إعادة فحص افتتاح Windows

- افتح المشروع في Unity 6000.3.23f1 بعد تنزيل الفرع. أعد استخدام كاش المحرر الموافق وموارد URP ‏17.3.0.
- من PowerShell شغّل `Migration/Tools/BuildWindows.ps1 -Unity path/to/Unity.exe -Output path/to/11.11.exe -Verify`. ثم شغّل `Migration/Tools/TestWindows.ps1 -Player path/to/11.11.exe -Evidence path/to/review -Motion Full` وكرّر ببينة مختلفة مع `-Motion Reduced`. كل تشغيل يستعمل حفظًا معزولًا جديدًا. للتصدير القابل للعب احذف `-Verify`.
- المرجع المرسوم هنا Windows 1280×720 ‏Direct3D11 على Intel UHD. البناء التحققي من كاش `OpeningUnityBatch` استخدم المشاهد نفسها وإصدارات الحزم المثبتة. فيه إعداد حزم ومشروع مُخفّف خاص بالبناء المحلي؛ الملف المنشور يحتفظ بإعدادات مشروع المؤلف.
- فحوص المحرر التاريخية R01/R02/R04/R05/R06 تسجل تجربة المدخل السابقة بأزرار بدء ومتابعة منفصلة وتمرير التحميل بعد الضغط. لواجهة العنوان الحالية استخدم اختبار Windows أعلاه. عتبات التحميل والجهاز المرجعي واختبار اللاعبين من الخطة الأصلية ما زالت مفتوحة.
