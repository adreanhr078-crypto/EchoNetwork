## نتيجة المقارنة

عُرض V13 وV3 داخل Godot Compatibility بمادة وإضاءة استوديو متكافئتين، وتثبيت وضع السكون والتأطير. V3 أغنى بتفاصيل المعطف، لكنه يحمل عينين مضيئتين ومظهراً تكتيكياً متحولاً. مرجع الافتتاح المعتمد في CP-20260923-04 هو إنسان بزي مدرسة قبل التحول. توجيه المالك باستعمال النموذج الأجمل لا يحذف هذا الترتيب القصصي.

حُفظ النموذجان ولم يُستبدل اللاعب الحي بـV3. المسار الفني: اعتماد V3 مصدراً محفوظاً، تعديل الزي والعينين والتشوهات وفق المرجع، ثم مقارنة داخل الغرفة وقبول الحركة والخامات والميزانية؛ أو توظيفه لاحقاً إذا طابق مرحلة مسموحة. لا حاجة لتوليد مدفوع جديد لمجرد وجود اسم 8K، ولا يُفترض تحميل خامة 8K كاملة على الهاتف دون قياس.

الدليل: `audits/evidence/echo-uniform-material-study.png` و`echo-8k-v3-material-study.png`. ليست المقارنة اختبار أداء هاتف أو قبولاً نهائياً للشبه بالمانهوا.

## Higgsfield: ما ثبت وما لم يثبت

فُحص مشروع الحساب الموجود [11.11 Echo Network — G0 Blender Bridge](https://higgsfield.ai/3d-jutsu/63a65cb7-da4a-45a7-8f0a-a91d21d2d2eb) قراءةً فقط: revision 5؛ ملفات Blender وGLB، وعملية الاستعلام `echo-g0-readiness-20260928-01` نجحت على Blender 5.2.0 LTS، وأظهرت الأرضية والسقف والمنصة والجدران والباب والإضاءة والكاميرا. لم يُعدل المشروع، ولم ينتج هذا الاستعلام أصلاً جديداً أو توليداً مدفوعاً.

[توثيق 3D Jutsu الرسمي](https://higgsfield.ai/blog/higgsfield-3d-jutsu) يصف مشهداً قابلاً للتحرير وتصدير GLB/MP4 وإدخال نموذج GLB. [تكامل Blender الرسمي](https://higgsfield.ai/mcp/scene-builder?tab=chatgpt) يوفر أدوات لمشهد Blender محلي. هذا لا يثبت أن فيديو Flow عشوائياً يُحوّل مباشرة إلى شخصية لعبة بجلد وعظام وتحريك صالحين. يُستخدم الفيديو مرجعاً للحركة والتكوين حتى تُنجز تجربة قدرة محددة وتُفحص نتيجتها.

Blender المحلي المحمول 5.2.1 LTS استُخدم فعلاً لتحليل التحريك. الاعتماد السحابي وواجهة التوليد المدفوعة قناتان منفصلتان. اعتماد API محفوظ مشفراً خارج Git. لا مفاتيح في التقرير. لم يُرسل توليد مدفوع جديد في هذه المراجعة؛ تبقى صورة دراسة الإضاءة السابقة مرجعاً مستقلاً. لا ادعاء باستعمال Flow أو تحويله هذه المرة.

## اتصال التحريك المحلي الذي استُعمل فعلاً

بعد توجيه المالك باستعمال ميزات التحريك، ثُبت `fnf-blender-mcp` 0.2.2 في مجلد مستخدم خارج المشروع، وسُجل باسم `higgsfield-use-blender`. نجح doctor ثم اتصال MCP SDK فعلي على الجهاز: bl_health وملخص المشهد وقراءة مهارة التحريك وفتح ملف V3 المحفوظ وقياس WAKEUP. Blender 5.2.1 LTS؛ 24fps، إطارات 1–72؛ أدنى الجسم في العينات -0.01867م في مقياس المصدر، ويحتاج ضبط أرضية عند التصدير. ملف `ECHO_8K_WAKE_MCP_AUDIT_2026-09-28.json` يسجل النتيجة. لم يُحفظ فوق الأصل ولم يُدمج التحريك. تسجيل MCP وحده لم يكن دليل اتصال؛ جلسة SDK هي الدليل. لا استهلاك أرصدة من العمليات المحلية.

واجهة API العامة [تصف توليد الصور والفيديو](https://docs.higgsfield.ai/docs)، بما فيها Genjutsu لنقل حركة فيديو. لم نثبت وصولاً إلى 3D Jutsu عبر المفتاح المدفوع؛ وصلنا إليه فعلياً عبر اتصال الحساب المتاح. غياب واجهة عن ملف OpenAPI وحده لا يثبت أنها غير متوفرة. تُفصل هذه الحقائق عند اختيار مسار العمل؛ لا يُسمى تحرير Blender المحلي توليداً سحابياً مدفوعاً.
