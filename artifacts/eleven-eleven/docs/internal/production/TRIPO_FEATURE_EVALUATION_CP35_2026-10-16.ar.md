# CP35 — تقييم Tripo للعبة / تجربة عملية جزئية

التاريخ: 16 أكتوبر 2026. الحالة: IN_PROGRESS؛ استكمال اختبارات الموقع BLOCKED مؤقتًا باتصال المتصفح، والتأهيل داخل Godot UNVERIFIED. هذه دراسة إنتاج معزولة، ولا تمثل أصلًا مقبولًا للإصدار.

## الحكم الحالي

Tripo واعد لتسريع إنشاء نماذج أولية وخامات وأصول مختارة. تجربة كينجا أعطت شكلًا أكثر قابلية للفحص من المصدر القديم: ذراعان في T-pose، يدان خارج الجيوب، أصابع ظاهرة، ومعطف مفتوح بين الساقين. لا يثبت ذلك جودة الأوزان أو التمثيل أو صلاحية النموذج للعبة. توصية دفع اشتراك بهدف أنيميشن احترافي لجميع الشخصيات ما زالت مؤجلة حتى تجربة تنزيل واستيراد فعلية.

## ما جُرّب فعلًا

| الميزة | الدليل الفعلي | الحكم المحدود |
|---|---|---|
| صورة إلى 3D | صورة كينجا الأصلية رُفعت؛ مرشح P2 واحد اكتمل | مفيد لبداية إعادة التصميم؛ ليس قبولًا نهائيًا |
| Smart Mesh P2 / Quad | طلب 20000 وجه؛ الواجهة عرضت 22633 وجهًا و21282 رأسًا | تم التنفيذ؛ عدد مثلثات التصدير وتوزيع الحواف غير مفحوصين محليًا |
| توليد الخامة | اكتمل؛ تمت مشاهدة الأمام والجانب والخلف | تماسك أولي واعد؛ الخرائط والدقة والتظليل داخل المحرك غير مؤهلة |
| Humanoid / Mixamo Rig | اكتمل؛ تمت مشاهدة العظام وسلاسل اليدين | تجهيز هيكل نجح في الموقع؛ عدد العظام والجلد والوجه غير موثقين بملف |
| مكتبة الحركة | hit_to_body_01 اكتملت وعُرضت، ثم توقفت عند 0.84 من مدة الواجهة 1.29 ثانية | الحركة المرئية أقرب لوقفة دفاع مقاتل؛ لا تُعتمد لدور كينجا المستضعف. فحص كامل الإطارات والتماس والتقاطعات ما زال مفتوحًا |
| FBX / Blender Export | محاولة فعلية فتحت Upgrade | BLOCKED بالخطة؛ لم ينزل ملف، ولم يُشترَ اشتراك |

ملاحظة الحركة الأخيرة مستندة إلى المعاينة المرئية السابقة في نفس العمل. لم تُحفظ لها لقطة مستقلة قبل تعطل التحكم، لذلك ليست حزمة قبول قابلة لإعادة التحقق. لقطة الهيكل المحفوظة تثبت الهيكل الظاهر فقط.

## الميزات التي دُرست ولم تُختبر عمليًا بعد

| الميزة | الاستخدام المحتمل للعبة | الاختبار المطلوب |

| HD H3.1 | مصدر تفصيلي لشخصية أو عنصر قريب من الكاميرا | مقارنة بنفس المرجع؛ لا قبول اعتمادًا على اسم HD |
| H2.5 | مسار تنزيل مؤقت محتمل ضمن Free | فحص الخيار والسعر الحي ثم إنشاء وتنزيل مرشح؛ لم يحدث بعد |

| Retopology / تقليل الوجوه | نسخة أخف مع حفظ الظل الخارجي والأصابع | قياس الأعداد والـUV والتشوه بعد التصدير؛ غير مجرّبة |
| Smart UV | تجهيز توزيع الخامات | فحص التداخل والتمدد والحواف؛ غير مجرّبة |

| Texture Edit / Magic Brush | تصحيح مناطق صغيرة أو توحيد خامة | تجربة نسخة مشتقة وفحص الحواف من عدة زوايا؛ غير مجرّبة |
| Remove Lighting / PBR | خامة تتأثر بإضاءة غرفتنا | مقارنة تحت إضاءتين وفحص الخرائط الفعلية؛ غير مجرّبة |
| Text-to-Motion | حركة جسم مخصصة عند غياب preset مناسب | فعل قصير واحد محدد؛ لا نفترض وجود تمثيل وجه أو أصابع دقيق |
| Text-to-3D / Generate in Parts | عناصر ثابتة مختارة وأجزاء معمارية | عنصر صغير من الغرفة الحالية؛ لا غرفة كاملة غير قابلة للتعديل |
| DCC Bridge / Godot | تسهيل نقل الملفات | تنزيل محلي واستيراد وتحقيق المحاور والمقياس والخامات؛ غير مجرّبة |
| Batch Generation | تنويعات بعد نجاح أصل نموذجي | مؤجلة حتى قبول أصل واحد وكلفته، وليست أولوية اختبار الرصيد |

هذه البنود موثقة أو ظاهرة في واجهة المنتج؛ قراءة الوصف الرسمي ليست اختبارًا. لم نجرب كل ميزات Tripo، ولم نختبر مخلوقات أو طباعة أو جميع صيغ الملفات لأنها لا تحسم حاجة اللعبة الحالية.

## الرصيد والقيود

بدأ حساب Studio بـ200 رصيد. هندسة P2 كانت تجربة مجانية (0)، والخامة 20، والـRig 20. آخر رصيد مرئي 160؛ هذه ملاحظة مؤرخة وليست قراءة حية بعد انقطاع التحكم. لم تُلاحظ خصومة مستقلة للحركة؛ لا ننسب لها تكلفة مخمّنة. لا صرف جديد في جولة فحص الاتصال هذه.

مفتاحا API المختلفان فُحصا في العمل السابق، كلاهما 0 متاح / 0 مجمّد؛ لا نستخدم رصيد Studio كأنه رصيد API. لا أسرار محفوظة في التقرير.

الخطة الرسمية Free: نماذج عامة، استخدام غير تجاري، وتنزيلات H2.5 محدودة. Pro تعرض 3000 رصيد شهري وحقوق استخدام تجاري وصادرات أوسع. التحقق الرسمي: https://www.tripo3d.ai/pricing . السعر والعروض والفوترة تختلف بين صفحة الحساب والصفحة العامة؛ لا توصية بسعر قديم أو عقد سنوي. لا نفترض أن ترقية لاحقة تمنح نموذج Free السابق حقوقًا رجعية؛ يلزم تحقق قبل أي استعمال تجاري.

## حدود القيمة للغرف والشخصيات

أفضل مرشحين للاختبار التالي: كينجا كحالة جسم وتمثيل، وعنصر ثابت واحد أو قطعة جدار مزخرفة قابلة للتكرار. الحائط المسطح والوصلات الدقيقة والفتحات والتصادمات تُضبط محليًا؛ توليد غرفة مغلقة كاملة لا يثبت قابليتها للعب أو سهولة تعديلها. زيادة الأجزاء قد ترفع نداءات الرسم، وزيادة دقة الخامات قد ترفع الذاكرة.

المؤثرات والجو والغموض يحتاجون إخراجًا وإضاءة وصوت مؤثرات فقط وكاميرا داخل Godot. نموذج 3D يمكن أن يكون مكوّنًا للمؤثر، لكنه لا يثبت نجاح المؤثر أو المشهد. Echo وGolden محفوظان؛ لا سبب حاليًا لإعادة توليد حركة Echo المقبولة أو استبدالها بوقفة جاهزة.

## العائق وخطة الاستكمال المحددة

تعذر قراءة الصفحة الحالية والتقاطها بعد محاولتي ربط مستقلتين، ثم تعذر إرفاق تبويب استعادة جديد. مخزون التبويبات بقي ظاهرًا؛ العائق اتصال التحكم وليس رفضًا من Tripo أو دليل انتهاء رصيد. لم يُعد تشغيل التطبيق ولم تُغلق نوافذ المالك. لا تكرار صرف أو تخمين حالة المهام عبر روابط داخلية.

1. استعادة اتصال المتصفح ثم قراءة الرصيد وحالة الأصل، قبل أي صرف.
2. فحص hit_to_body_01 من البداية والنهاية، ثم hit_to_body_02 وidle أو خوف؛ حركة واحدة كل مرة مع تحقق التكلفة واليد والمعطف والقدمين.
3. مسار تنزيل مسموح: H2.5 مؤقت إذا كان متاحًا، أو تصدير P2 بعد قرار المالك بشأن الخطة؛ لا تجاوز لبوابة الدفع.
4. اختبار Blender ثم Godot معزول: الوضع المرجعي، المقياس، المحاور، الجلد، الجسم واليد والوجه والمعطف، الخرائط ومظهر الإضاءة. لا دمج قبل مراجعة أرجون المحددة والتحقق المحلي.
5. اختبار عنصر ثابت واحد للتقسيم وخامة وتصغير مناسبين، ثم مقارنة جودة مرئية وكلفة داخل الغرفة الحالية. لا استبدال عشوائي لكل الغرف والحيطان.
6. بعدها يصدر حكم اشتراك مبني على صلاحية ملف فعلي وتكلفة الأصل المقبول، لا عدد النماذج المعلن. ميزانية التجربة الأصلية 200؛ المتبقي المرصود 160، ولا توسيع مالي تلقائي.
