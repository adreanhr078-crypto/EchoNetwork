## المرجع والحدود

[خطة الرحلة](ECHO_SYSTEM_TO_HOSPITAL_PLAN_2026-09-28.ar.md): 90–120 دقيقة هدف تصميم، صوت ياباني وترجمة AR/EN، نجاة بشرية قبل عقد زيرو. الفن والصوت والتحريك أثناء كل دفعة. معيار الصيانة 5–8 دقائق المصقول لم يُقبل بعد؛ لا توسع كينجا وزيرو والمستشفى قبل بوابة الجودة.

الهاتف الفعلي و20 دقيقة أداء وخمسة لاعبين والمرور اليدوي الكامل وiframe غير متحققين. 13 مخالفة وسائط ويب سابقة باقية. قبض الأصابع واتجاه راحة اليد، انتقالات الجسم والجري والقفز والهبوط، الخامات والتنوع والإخراج والقبول السمعي تحتاج صقلاً. إضاءة الخدمة أصبحت أخفض وأوسع لقراءة الأرض؛ لا يعني ذلك قبول الإضاءة الفنية.

رصيد API يعمل لتوليد الفيديو والصوت؛ لا يشمل وكيل Jutsu المدفوع وفق شروط الخدمة. الحساب المرتبط بالموقع ظهر free/0. نموذج rigging في الكتالوج لا يثبت وجود إرسال 3D متاح. سؤال OAuth المحدد السابق بلا جواب؛ لا يوجد هيكل بديل معتمد. لا تعاود توليد الطلب المكتمل؛ اقرأ السجل أولاً.

فحص مسار Agent API الرسمي الجديد `POST /v1/agent/sessions` أعاد 403 بهذه البيانات في CP-03؛ لم يبدأ وكيل أو توليد جديد. الرصيد وحده لا يثبت تفعيل خدمة الوكيل. السجل الآمن في `art/production/maintenance-jutsu-v1/agent-access-20260929.json`؛ الاعتماد المشفر خارج المشروع.
