# بطاقة المتابعة الحالية — EchoNetwork / 11.11

آخر تحديث: 2026-09-29. اقرأ البطاقة والخريطة ثم آخر نقطة متابعة ذات صلة؛ القواعد والذاكرة والكانون تبقى إلزامية.

## آخر تنفيذ مثبت

- نقطة `CP-20260929-01`: غرفة صيانة من Jutsu إصدار 3، تسلق وتعلق وصعود حافة وقفزة فجوة وحفظ مستقل، متصلة بالافتتاح في مشهد اختياري.
- ثلاث حركات على هيكل إيكو الأصلي؛ صُححت خريطة الذراع اليسرى واتجاه الركبتين وتوجيه القدمين وطي الكاحل وتزامن صعود الحافة. لا يوجد إيكو جديد أو هيكل مولد معتمد.
- مسارا الافتتاح والمسار المتصل نجحا عبر إدخال اللاعب في الترتيبين. الفحوص والتصدير موثقة في [تقرير الدفعة](JUTSU_MAINTENANCE_2026-09-29.ar.md).
- طلب API واحد لفيديو مرجعي 3 ثوانٍ؛ $0.693 تقدير منشور، الفاتورة غير متحققة. ليس تحريك شخصية ولا صوتاً مدمجاً. لا استهلاك Flow.
- الافتتاح مقبول جزئياً؛ الصيانة نموذج تأسيسي أقصر من معيار 5–8 دقائق المصقول، وليست جودة قنشن أو رحلة المستشفى المكتملة.

## المرجع المعتمد

[خطة رحلة إيكو إلى المستشفى](ECHO_SYSTEM_TO_HOSPITAL_PLAN_2026-09-28.ar.md): 90–120 دقيقة هدف تصميم، صوت ياباني وترجمة AR/EN، نجاة بشرية قبل عقد زيرو، فن وتحريك وصوت أثناء كل دفعة. سجل الدفعات مطابق في `GODOT_SYSTEM_EXECUTION_2026-09-28.ar.md`. بوابة المرحلة الحالية لم تُغلق.

## النواقص والحدود

- تحسين فني وحركي وسمعي ومعيار صيانة 5–8 دقائق؛ ثم غرف المراقبة والأمن وبقية الرحلة. كينجا وزيرو والمستشفى لم تُنفذ بهذه الدفعة.
- الهاتف الفعلي و20 دقيقة أداء وخمسة لاعبين والمرور اليدوي الكامل وتكامل iframe غير متحققين. 13 مخالفة وسائط سابقة باقية.
- وكيل Jutsu المدفوع: اختيار النموذج في Edge أظهر «All credits used»؛ الحساب المرتبط رصيده 0 وخطته free. رصيد API لا يثبت تغطية وكيل الموقع. لا اشتراك أو توليد وكيل مدفوع جديد.
- نموذج `3d_rigging` موجود في الكتالوج، لكن إرسال 3D غير مكشوف في الأدوات المرتبطة. CLI رسمية مثبتة خارج المشروع؛ سؤال الموافقة المحددة على ربطها وحفظ الدخول ما زال بلا جواب صريح. لا يُضغط Allow قبل الجواب.

## التالي بالضبط

راجع تقرير الدفعة وأدلة الرجلين، ثم اكمل صقل معيار الصيانة المحدود: تفاعل خدمة واضح، صوت فعلي، حركات وكاميرا وخامات، ومراجعة 1080p وشاشة الهاتف. تحقق من الحساب وطريق إرسال 3D قبل تجربة هيكل بديل واحد يحافظ على شكل إيكو. لا تنتج بقية الغرف بكثرة قبل قبول معيار الجودة.
