# سياسة إنتاج الغرف — توجيه المالك23 أكتوبر2026

المالك يطلب صقل المختبر الحالي أولًا، ثم تطبيق هذا المسار على الغرف التي تقل عن المستوى المطلوب. الغرف الجيدة، ومنها الغرفة الأولى بحسب تقييمه، لا تُعاد لمجرد توحيد الأدوات. هذا لا يعتمد المختبر أو يغيّر PART_3.

1. قياس الغرفة ومسار اللاعب والمعالم والتفاعلات وقراءة Canon قبل التصميم.
2. أربع صور متسقة: دخول، عكس، جانب، ومعلم رئيسي؛ ثم مشهد Flow مرجعي. تُراجع المادة الفعلية كاملة، مع SFX_ONLY.
3. اختيار الأداة بحسب الجودة: Tripo للموارد أو مجموعة مجزأة أو غرفة كاملة إذا صلحت؛ Blender للهندسة والتعديل والمقاسات؛ Godot للعب والشيدر والمؤثرات والكاميرا. توليد الغرفة كاملة اختياري، ولا يُقبل إن أفسد الداخل أو المداخل أو الهوية.
4. Multi-view يستخدم2–4 صور لنفس الشكل الثابت، بمقياس وإضاءة وتصميم متطابق. زوايا سينمائية داخلية غير متطابقة لا تُعامل تلقائيًا كواجهات هندسية. توليد زوايا جديدة تقدير، لا قياس للأسطح المخفية.
5. استثمار ميزات Tripo الملائمة: تجزئة/إكمال أجزاء، Retopo وUV، خامات/PBR، تفصيل مناسب لمسافة المشاهدة. الهيكلة والتحريك حيث يلائمان المورد؛ لا يُفرض هيكل بشري على معدات ميكانيكية، ولا تُستبدل حركة V31/Golden المحمية.
6. أذن المالك بعد تفعيل الاشتراك باستعمال الكريديت والميزات لتحسين الجودة. الرصيد المرئي عند التفعيل3145؛ ليس سعر API أو تفويض شراء آخر. تسجيل تكلفة كل مهمة والاحتفاظ بمصدرها ونتيجتها، واستكمال المهام المحفوظة بدل تكرارها. الاستهلاك وحده ليس معيار نجاح.
7. مؤثرات ومشاهد تفاعلية ذات غرض وأثر فعلي، مرتبطة بمرحلة Canon والاختيار الصريح. لا تُستبدل اللعبة بفيديو، ولا تضاف قدرات أو قرارات من العرض.
8. قبول الغرفة بعد مراجعة اللقطات الأربع والمسار الحقيقي والكاميرا والتلامس والقراءة والحفظ والاستئناف وPause/Skip/Reduced Motion/الصوت والأداء والحمل. الصور المرجعية والتوليد والاختبارات العددية لا تثبت التفوق على قنشن أو جودة نهائية.

الحد الحالي: المختبر REFINE؛ لم يُعتمد بصريًا. الإنجاز الفني والوظيفي والأداء والحزمة يُسجل كل منها بدليله وبصمات مصدره.
