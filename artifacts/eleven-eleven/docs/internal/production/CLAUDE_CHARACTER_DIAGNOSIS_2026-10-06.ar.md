## تصحيحات مهمة عند استعمال التقرير

1. **Golden محفوظ**: الحارس المحلي بعد هذه الأعمال أعطى PASS لكل 192 ملفًا محميًا، وتسعة اختبارات pipeline نجحت. ملاحظة Claude عن ملفات Git موسومة M ليست دليل تغيير بايتات المرجع. لا إعادة خبز أو تعديل للـGolden Walk المجمد؛ 192 PASS دليل سلامة ملفاته، لا اعتماد الهيكل الجديد.
2. **طريقة النقل الحالية ليست نسخ دوران محلي**: أداة Golden تستعمل تحويل world/rest المجمد. تفسير Claude لانعكاس المرفق باعتباره نقلًا محليًا كان استنتاجًا غير مقاس؛ لا نعتمده كسبب ثابت ولا نستبدل المعادلات بسببه.
3. **Run محاولة 02 موجودة**: اكتملت محليًا أثناء مراجعة Claude، ولم يراجعها هو. 25 عينة أصلية عند 30fps؛ replay PASS حتى 0.000004266m و0°، والمقارنة المرئية حسنت حمل الساعدين أمام الجسم لكنها بقيت FAIL للهيئة/الكفين/القماش. لا تصدير أو دمج.
4. **قناع الملابس قبل تعديل الأوزان**: قطعة Mesh واحدة أو اتصال بعد لحام المواضع لا يثبت وحده أن الملابس والجسم يجب تقسيمهما. تحديد السطح بأطلس UV والعرض الفعلي والأوزان يلزم قبل نقل تأثير رؤوس قد تكون من الكم فعلًا.
5. توصيات Claude وطلبه تفويضًا لتعديل الأوزان هي مقترحات منه؛ لا تغير تعليمات المالك. الأصل وGolden محفوظان، والتصحيح المشتق المعزول يجب أن يبقى مقاسًا وقابلًا للمراجعة قبل أي دمج.

## خطة التصحيح وبوابات القبول

1. تصحيح مرجع الكف من هندسة اليد ومعالم مصدر الأصابع الفعلية؛ مراجعة أمامية وجانبية وعلوية، واتجاه وطول وتناظر مقاس. احتفظ بمرجع v1 المرفوض للمقارنة.
2. تشخيص الكتف ونطاق الإبط داخل المرجع فقط. قِس تمدد أضلاع ومساحات المثلثات في الوضعية والحركة؛ فرّق جلد الذراع عن الكم والجذع والحقيبة بأقنعة موثقة قبل أي تعديل أوزان محدود. لا smoothing شامل ولا تغيير للساقين أو الرأس لتغطية العيب.
3. اجتياز فحص الكفين والكتف والملابس والتداخل في المصدر مقابل الهدف، ثم فحص كل عينة الجلد والنعل والاتصال بالأرض ونهاية الدورة. الحدود التي اقترحها Claude للتمدد والتداخل مؤشرات أولية تحتاج تثبيتًا على القطعة الأصلية، وليست اعتمادًا مسبقًا.
4. تصدير الحركة لا يحدث إلا بعد PASS عددي وبصري مرتبط ببصمة ملف Blender نفسه، ثم replay داخل Godot مستقل وفق إعداد Golden المجمد. لا AnimationTree أو تعديل مفاتيح المصدر أو تعويض IK أثناء هذه المقارنة.
5. مراجعة أول إطار للوجه وملامحه، وحركة اليد والأصابع، وتحويلات الحوض داخل كبسولة اللاعب والكاميرا في runtime قبل الدمج. بعد ذلك فقط تُراجع الغرفة كاملة والمتعة والأداء والهاتف.

## حدود التقرير

Claude لم يفتح `.blend`، ولم يفحص UV أو normals أو التشوهات في Godot أو الأداء والهاتف. لا يثبت هذا التقرير قبول الشخصية أو الفن أو تفوقًا على Genshin، ولا يمثل إصلاحًا مكتملًا. رصيد Higgsfield يولد وسائط للمشهد السينمائي؛ لا يعالج هذه العيوب الهيكلية في الشخصية أو الغرف التفاعلية.
