## استعمال Higgsfield الفعلي

نجح اعتماد بيانات الدخول الكاملة. وُلّدت **صورة واحدة فقط** عبر `z-image/turbo` بدقة 2K ونسبة 16:9، لتحديد قيم الإضاءة والمزاج. الأصل وسجل الطلب والبصمة في `art/production/opening-lighting-study/`. اكتمل الطلب وتم تنزيل الصورة وفحصها.

الصورة مرجع إضاءة، وليست لقطة لعب أو مشهداً ثلاثي الأبعاد أو اعتماداً لشكل الكبسولة والكانون. الكبسولة المرسومة تختلف عن المجسم القائم. استُعملت القيم العامة فقط، وأُعيد استعمال أصول الغرفة الموجودة. لم تُضف الصورة إلى تشغيل اللعبة أو APK.

السعر المنشور وقت الطلب **0.015 دولار للصورة**، بحسب [صفحة النموذج الرسمية](https://open.higgsfield.ai/models/z-image/turbo/playground). الخصم الفعلي وفاتورة الطلب غير متحققين، وحقل `actualChargeUsd` فارغ لهذا السبب؛ لا يُحسب cashback على أنه توليد مجاني.

حُفظ الاعتماد مشفراً بحماية Windows للمستخدم الحالي خارج المستودع في `.codex/secrets/echo-higgsfield.dpapi`. لا يُرفع أو يُضمّن في اللعبة، ولا ينتقل تلقائياً إلى حاسوب آخر. لا يوجد اعتماد مكشوف في سجل الأصل. لم يبدأ Blender أو تحويل فيديو Flow؛ تبقى هذه التجربة في الدفعة التاسعة.

## الأدلة وحدودها

- `audits/evidence/opening-baseline-{1280x720,1920x1080}.png`: النسخة الأولى قبل إصلاح الحدود والإضاءة والقشرة وإزاحة الجسم.
- `opening-without-outline-*`: تجربة عزل الحد، تكشف البياض المفرط؛ ليست مرشح تسليم.
- `opening-candidate-*`: وسيط قبل إصلاح إزاحة الجسم؛ ليس النتيجة النهائية.
- `opening-final-*`: عرض Godot فعلي بعد الإصلاحات، دون قائمة توقف، مع خمول مثبت وكتم وتقليل حركة. الاختبار ينهي الاستيقاظ برمجياً ليقارن الصورة؛ لا يثبت إكمال الافتتاح يدوياً.
- سجلات الأوامر والبناء تحت `.tmp/native-opening/`، خارج Git. ملفات اختبار العرض نفسها محفوظة لإعادة الإنتاج.

## التحقق

فحص البداية PASS. اختبارات Godot الحالية: `opening_slice_smoke.gd`، `native_opening_checkpoint_smoke.gd`، `native_pause_touch_smoke.gd`، `native_opening_visual_smoke.gd` PASS. الاختبار الجديد كشف خطأ حركة الجناح وصُحح قبل إعادة الفحص. محاولة أولى باسم `native_checkpoint_smoke.gd` غير الموجود فشلت في تحميل الملف؛ أُعيد الفحص بالاسم الصحيح ولا تُحسب المحاولة الأولى اختباراً للعبة.

التصدير التجريبي Windows وAndroid أُعيد بعد الإصلاحات. توقيع APK v2/v3 ومحاذاته PASS. تفاصيل النسخة الحالية في تقرير البناء. قبول المتعة والتحريك الكامل و720p/1080p بصرياً مع المالك والهاتف و20 دقيقة وخمسة لاعبين وiframe الكامل **UNVERIFIED**. بوابة المرحلة لم تُغلق.

فحص `npm run agent:postflight` PASS للمحتوى وTypeScript والاختبارات والبناء وdoctor. `git diff --check` PASS؛ Git ينبه إلى تحويل LF إلى CRLF المعتاد محلياً. فحص الاعتماد المشفر نجح دون إظهار قيمته، ولم توجد نسخته الكاملة أو Secret في الملفات المتغيرة. الملف الخاص بالإضاءة الأصلية محدود بالمشهد الأصلي؛ إصلاح التوهين والحد يقع في خامات مشتركة، فيلزم قبولها بصرياً في المشاهد اللاحقة عند الوصول إليها. لم تُقبل مشاهد الويب أو القتال بهذا التسليم.

## التالي ضمن الافتتاح

معالجة وجه ويد Echo المفرطي البياض، مظهر المحطة المؤقت، التجانس البصري والخطوط والعربية داخل حوار الغرفة، والتحريك غير المتخطى وتأطير الكبسولة والكاميرا. ثم مرور يدوي للمهمتين وترتيبيهما والصوت، مع اختبار اللمس والاستئناف والأداء على الهاتف. لا تكفي إضافة التفاصيل لبلوغ مستوى Genshin؛ جودة الأصول والحركة والإخراج والتحكم تحتاج قبولاً مستقلاً.
